# 校园网助手 · Dr.COM 网页认证自动登录工具

一个面向 Dr.COM（城市热点）Portal 认证校园网的单文件 Windows 桌面工具：双击即用、托盘常驻、掉线自动重连，并支持按“手机 / 电脑”两种终端类型选择计费名额。

> 适用于学校使用 Dr.COM 网关、浏览器打开网页输入账号密码才能上网的环境。不适用于 GiFi、锐捷 ePortal 私有客户端等其他认证体系。

## 特性

- **单文件、零依赖**：只有一个 `campus_net.ps1`，PowerShell 5.1 原生运行，无需安装模块或运行时。
- **图形界面 + 托盘常驻**：WinForms 界面，关闭窗口不退出；托盘右键可“立即登录 / 注销 / 退出”。
- **静默启动**：配套 `launch.vbs` 以隐藏窗口方式拉起，不弹黑框，可做成桌面快捷方式。
- **两种终端类型**：登录时按类型提交 `R6=1`（手机）或 `R6=0`（电脑），并在切换前自动调用 `mac/unbind` 清理 AC 上的旧绑定，否则旧类型会被沿用。
- **掉线自动重连**：定时检测在线状态，失败按 30 → 60 → 120 → 240 → 300 秒退避重试，恢复后自动复位。
- **精确识别本机会话**：同一账号可能有多台设备同时在线，工具按本机 IP / MAC 匹配会话，不会把别的设备的名额当成本机的。
- **只读诊断**：`-Status` 一屏输出网卡、配置、在线会话（含 `phone_flag`）、门户认证状态、外网连通性，排障第一步。
- **单实例保护**：互斥量保护，避免多个实例互相注销把会话搅乱。

## 快速开始

1. 把 `campus_net.ps1`、`launch.vbs` 放在同一目录（例如 `D:\DrcomLogin`）。
2. 复制 `config.sample.json` 为 `config.json`，填入账号、密码、认证地址；也可以启动后直接在界面里填写。
3. 双击 `launch.vbs`（或右键“发送到 → 桌面快捷方式”），在界面点“登录”。

登录成功后状态栏显示 `在线 · 手机名额` 或 `在线 · 电脑名额`，后面跟 IP、MAC 与已在线时长。

若首次运行被策略拦截，可在当前用户下放行一次：

```powershell
powershell -ExecutionPolicy Bypass -File .\campus_net.ps1
```

## 配置项

`config.json`（与脚本同目录，已被 `.gitignore` 排除）：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `account` | 学号 / 手机号（不含 `@运营商` 后缀） | `"20230001"` |
| `password` | 上网密码 | `"********"` |
| `portal` | 校园网认证页地址，即浏览器跳转到的那个 IP | `"http://172.25.251.2"` |
| `terminal` | `phone` 占手机名额，`pc` 占电脑名额 | `"phone"` |
| `autoRelogin` | 是否掉线自动重连 | `true` |
| `checkSeconds` | 检测间隔秒数（下限 15，实际不低于 30） | `30` |

界面上的填写内容在点“登录”时写回该文件。

## 命令行用法

```powershell
# 只读诊断：不改动任何会话，推荐排障第一步
powershell -ExecutionPolicy Bypass -File .\campus_net.ps1 -Status

# 自检：走完整的“注销 + 解绑 + 登录”链路并打印结果（会中断当前连接）
powershell -ExecutionPolicy Bypass -File .\campus_net.ps1 -Test
```

`-Status` 输出示例：

```

=== 门户首页（80 端口） ===
  在线=True 账号=***@unicom IP=172.24.39.61
```

运行时会在同目录生成 `config.json` 与 `campus_net.log`，两者都不入库。

## 实测环境

- Windows 10 / 11，Windows PowerShell 5.1
- Dr.COM 网关 `Server: DrcomServer1.0`，Portal `http://172.25.251.2`（80 端口登录页 `a79.htm`，801 端口 JSONP 接口）
- 验证结论：同一账号可同时持有 1 个电脑名额 + 1 个手机名额；切换类型必须先解绑 MAC 再登录。

## 已知限制

- 仅适配 Dr.COM 的 `a79.htm` 本地认证通道；新版 `/eportal/portal/login` JSONP 登录在部分学校返回“没有配置接入服务器”，故未采用。
- 只支持 IPv4；IPv6 场景未处理。
- 若学校启用了强制客户端或 Portal 页面改版，提交字段可能需要调整。
- 工具不保存服务器返回的诊断数据，排障依赖 `campus_net.log`。
