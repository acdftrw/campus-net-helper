# 常见问题

## 启动与运行

**双击没反应 / 一闪而过**
用命令行以可见模式启动一次，看报错：

```powershell
powershell -ExecutionPolicy Bypass -File .\campus_net.ps1
```

常见原因是执行策略受限，可用 `-ExecutionPolicy Bypass` 放行，或在「设置 → 允许本地脚本运行」中调整。

**提示“校园网助手已经在运行了”**
程序是单实例的，托盘里已有进程。双击右下角托盘图标即可打开；要强制重启，右键托盘「退出」后再启动。

**窗口关了，程序还在吗**
在。关闭窗口只是隐藏到托盘，自动重连继续工作。要彻底退出用托盘右键「退出」。

## 认证相关

**登录提示成功，但状态栏还显示离线**
服务端会话同步有约 10 秒延迟，稍等片刻程序会自动刷新。若超过 30 秒仍异常，运行 `-Status` 看是哪一层断了。

**切了终端类型，`phone_flag` 却没变**
AC 以「MAC + 类型」为键做绑定，必须先解绑再登录。程序已内置该步骤；若手工用其他工具测试，请先请求 `mac/unbind`。

**为什么日志写着“电脑名额”，但实际上是手机名额**
旧版本取的是在线会话列表的第一条，而该列表包含同一账号下**所有设备**的会话。现版本已改为按本机 IP / MAC 匹配。请更新到最新脚本。

**换了 Wi-Fi 后一直报“无法连接到远程服务器”**
重连后进程内的连接已失效。程序会在失败后丢弃连接重试；若仍不恢复，退出助手再启动即可。

**提示“门户不可达”**
先确认是否已连上校园 Wi-Fi（`ipconfig` 能看到 172.24.x.x 的地址），再确认认证地址是否为当前学校的门户 IP。不同校区、不同楼栋门户地址可能不同。

## 多设备

**同一账号的另一台电脑会不会被我踢下线**
不会。程序只注销本机 IP/MAC 对应的会话，另一台设备占的是另一个名额，互不影响。但若两台设备都试图占同一种名额，则后来者会顶掉先来者。

**怎么确认本机到底占哪个名额**
运行 `-Status`，找到 `online_ip` 等于本机 IP 的那条会话，看它的 `phone_flag`：`1` 为手机名额，`0` 为电脑名额。也可以看界面状态栏。

## 安全

**config.json 会被上传到仓库吗**
不会，`.gitignore` 已排除。但仍建议不要把整个目录打包外传，里面是明文密码。

**能多人共用同一份配置吗**
技术上可以，但同一账号会被反复顶号，不建议。
