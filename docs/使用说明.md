# 使用说明

## 一、安装与启动

1. 把 `campus_net.ps1` 与 `launch.vbs` 放在同一个目录，例如 `D:\DrcomLogin`。
2. 在该目录新建 `config.json`（可从 `config.sample.json` 复制），或启动后在界面里填写。
3. 双击 `launch.vbs`：以隐藏控制台的方式启动，只会出现一个窗口，不会有黑框。
4. 想放到桌面：右键 `launch.vbs` → 发送到 → 桌面快捷方式，重命名为「校园网助手」。

## 二、日常使用

1. 打开窗口，账号、密码、认证地址已按上次填写的内容带出，点「登录」。
2. 登录成功后状态栏显示「在线 · 手机名额」或「在线 · 电脑名额」，其后是 IP、MAC 与已在线时长。
3. 关闭窗口不退出程序，会缩到右下角托盘（盾牌图标），双击图标可重新打开。
4. 托盘右键菜单：显示主界面 / 立即登录 / 注销 / 退出。
5. 勾选「掉线自动重连」后，程序每 30 秒检查一次；掉线会按 30 → 60 → 120 → 240 → 300 秒退避重试，恢复后间隔复位。

## 三、开机自动启动（免手动）

目标状态：开机 → 连上 Wi-Fi → 程序自动以手机终端类型登录 → 全程无窗口、无弹框。

1. 在 `config.json` 中设置：

   ```json
   {
     "terminal": "phone",
     "autoRelogin": true,
     "startMinimized": true
   }
   ```

   `startMinimized` 让程序启动后直接缩进托盘，不抢焦点、不弹主窗口。

2. 新建开机启动项：在 `C:\Users\<你的用户名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup` 下新建 `校园网助手.vbs`，内容为：

   ```vbscript
   Set sh = CreateObject("WScript.Shell")
   cmd = "powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File ""D:\DrcomLogin\campus_net.ps1"""
   sh.Run cmd, 0, False
   ```

   放“启动”文件夹的好处是不需要管理员权限，且只在你登录后运行。

3. 验证：重启后不再打开界面，右下角托盘出现盾牌图标；把鼠标悬停或双击图标，状态栏应显示「在线 · 手机名额」。

开机后 Wi-Fi 可能比程序慢一步。此时程序会检测到「门户不可达且外网不通」，判定为网络未就绪，保持 30 秒间隔继续等待，而不会进入分钟级的失败退避；Wi-Fi 一就绪，下一轮就会完成认证。

要取消自启：删除“启动”文件夹里的那个 `.vbs` 即可，或在托盘右键「退出」后删除。

## 四、终端类型（关键）

「终端类型」下拉框决定占哪种名额：

- 手机（占手机名额）：登录请求带 `R6=1`，服务端 `online_list` 的 `phone_flag` 记为 `1`。
- 电脑（占 PC 名额）：`R6=0`，`phone_flag` 记为 `0`。

切换类型时，程序会先调用 `mac/unbind` 清掉网关（AC）上「MAC + 终端类型」的旧绑定，再重新登录。这一步是必须的：不解绑时 AC 会沿用旧类型，登录虽返回成功，但 `phone_flag` 一直不变。

首次以手机身份登录成功后，该 MAC 会以「手机」记录在 AC 上，之后注销重登仍会判为手机名额；要改回电脑名额，把下拉框切到「电脑」再登录一次即可。

## 五、文件说明

| 文件 | 作用 |
| --- | --- |
| `campus_net.ps1` | 主程序，界面 + 全部认证逻辑 |
| `launch.vbs` | 静默启动器，避免弹出 PowerShell 窗口 |
| `config.json` | 账号、密码、认证地址、终端类型、检测间隔（含敏感信息，不要外传） |
| `campus_net.log` | 运行日志，出问题先看这里 |

## 六、排障入口

```powershell
# 只读诊断，不改动会话
powershell -ExecutionPolicy Bypass -File .\campus_net.ps1 -Status

# 完整链路自检（会中断当前连接）
powershell -ExecutionPolicy Bypass -File .\campus_net.ps1 -Test
```

`-Status` 会依次输出：网卡 IP/MAC → config 配置 → 801 接口查到的在线会话（含 `phone_flag`）→ 门户首页是否已认证 → 外网是否可达。哪一层断了，一眼能看出来。

## 七、注意事项

1. 同一账号可能允许多台设备同时在线，判断“本机占哪个名额”不能看接口返回的第一条会话，必须按本机 IP / MAC 匹配。
2. 认证成功后服务端有约 10 秒的同步延迟，立刻查询可能仍显示旧状态，属正常现象。
3. 更换 Wi-Fi 或重连网络后，进程内可能残留失效连接；程序已主动丢弃连接，但若状态异常，重启助手最稳妥。
4. 用电脑占手机名额与学校按终端类型计费 / 限速的策略不一致，是否允许以学校用户协议为准，风险自担。
